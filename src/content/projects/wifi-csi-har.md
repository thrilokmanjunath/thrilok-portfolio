# Wi-Fi CSI-Based Human Activity Recognition

An innovative research project exploring non-invasive Human Activity Recognition (HAR).

## Core Capabilities

- **Privacy-Preserving AI**: Uses Wi-Fi signals (CSI) instead of video feeds to detect and classify human activities.
- **Deep Learning**: Implements advanced temporal modeling using Long Short-Term Memory (LSTM) networks in PyTorch to decode signal perturbations.
