# Machine Learning Implementations

A collection of foundational and advanced Machine Learning models built to solve practical classification, regression, and data segmentation problems.

## Highlights of Included Projects

1. **Customer Segmentation (Clustering)**: Implemented unsupervised K-Means and Hierarchical clustering algorithms to group customer profiles based on spending habits, visualized via principal component analysis (PCA).
2. **Housing Valuation (Regression)**: Developed multiple linear, ridge, and random forest regression pipelines, utilizing feature selection and scaling to forecast market prices.
3. **Credit Risk Classifier (Classification)**: Trained logistic regression and gradient boosting models to classify credit default likelihoods, handling highly imbalanced datasets using SMOTE (Synthetic Minority Over-sampling Technique).
4. **Statistical Evaluations**: Every script outputs cross-validation averages, validation metric logs, and plots mapping model performance convergence.
